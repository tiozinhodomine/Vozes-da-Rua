# Vozes da Rua

**Descrição**
-O Vozes da Rua é uma plataforma web criada para aproximar pessoas que desejam contribuir com a causa social de organizações que atuam diretamente no apoio a pessoas em situação de rua.

-A plataforma funciona como uma ponte: o usuário pode conhecer organizações, descobrir suas iniciativas e encontrar diferentes maneiras de contribuir. A proposta é transformar a vontade de ajudar em uma ação mais acessível, organizada e consciente.

-O projeto nasceu da ideia de utilizar a tecnologia não apenas para informar, mas para conectar pessoas e iniciativas que já fazem a diferença na sociedade.

**Funcionalidades**
*🏠 Página inicial com a apresentação da plataforma e seus principais objetivos;*

*🤝 Organizações para visualizar iniciativas e instituições sociais;*

*👤 Perfil das organizações com informações e formas de contribuição;*

*💚 Quero ajudar com possibilidades de participação e apoio;*

*📖 Sobre nós apresentando o projeto e sua equipe;*

*🗺️ Área para mapa, planejada para uma futura integração com serviços de localização;*

**Como funciona**
-O funcionamento da plataforma foi pensado de maneira simples:

Pessoa interessada em ajudar
            ↓
     Acessa a plataforma
            ↓
   Conhece as organizações
            ↓
   Encontra uma forma de ajudar
            ↓
       Entra em ação

**Como Usar**

Pré-requisitos

Antes de começar, você precisa ter instalado:

Node.js

npm (instalado junto com o Node.js)

Git (opcional, caso utilize o repositório)

Instalação

Clone o repositório:

git clone <URL-DO-REPOSITORIO>

Entre na pasta do projeto:

cd vozes-da-rua

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm run dev

O Vite exibirá no terminal o endereço local para acessar a aplicação, normalmente:

http://localhost:5173

Executar a versão de produção

Para gerar a versão otimizada:

npm run build

Para visualizar a versão de produção localmente:

npm run preview

**Tecnologias Utilizadas**

Front-end

React — construção da interface e dos componentes;

TypeScript — tipagem e maior segurança no desenvolvimento;

Vite — ambiente de desenvolvimento e build;

Tailwind CSS — estilização e criação da interface;

React Router — navegação entre as páginas da aplicação.

**Organização**

O projeto utiliza componentes reutilizáveis e uma estrutura organizada para facilitar a manutenção e evolução da plataforma.

src/
│
├── assets/       # Imagens, ícones e identidade visual

├── data/         # Dados utilizados pela aplicação
├── routes/       # Configuração das rotas
├── styles/       # Estilos globais e tema
│
├── App.tsx       # Componente principal
└── main.tsx      # Inicialização da aplicação
